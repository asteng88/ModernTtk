# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **ModernTtk** (for example, in the IPC serialization helpers or subprocess worker), please report it responsibly:

1. **Do not** open a public GitHub issue for undisclosed security vulnerabilities.
2. Use GitHub's **Private Vulnerability Reporting** ("Security" tab -> "Report a vulnerability") on [asteng88/ModernTtk](https://github.com/asteng88/ModernTtk/security).
3. Include a clear description of the issue, steps to reproduce, and affected Python / OS versions.

You can expect an acknowledgment within 72 hours and a coordinated fix/disclosure plan once confirmed.
